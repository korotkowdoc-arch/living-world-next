## Готово и проверено локально (без живой БД)

- [x] Новый независимый исходный проект, без переноса старой гигантской панели.
- [x] Mobile-first статический веб-клиент, не Windows-приложение.
- [x] Создание мира из одного естественного описания.
- [x] Директивы естественным языком и неизменяемые пять принципов рассказчика.
- [x] Классификация явных запретов на примирение и проверка таких событий в JavaScript.
- [x] Ветки с воспроизведением только подтверждённых предков.
- [x] Логика причинной памяти: персонажи, направленные отношения, знание, деньги, имущество, обязательства, события вне кадра.
- [x] Защита от заявлений «ноль фактов» при неполном сохранении.

## Известные ограничения / риски

- Новый репозиторий `korotkowdoc-arch/living-world-next` уже содержит первую версию в `main`. Новые изменения должны публиковаться безопасными fast-forward коммитами поверх её истории.
- Нет автоматической AI-генерации в веб-клиенте: пользовательский ChatGPT-план не предоставляет API-ключ сайту.
- OAuth-контур реализован в исходниках, но не развернут и не проверен на реальном ChatGPT: **полный цикл игровой истории ещё не подтверждён**.
- Парсер естественного языка эвристический: не все имена/формулировки извлекутся структурно. **Исходное правило всегда сохраняется дословно**.
- Блокировка примирения в коде касается распознанных и размеченных событий. Не гарантирует анализа всей художественной прозы; смысловые тесты остаются обязательными.
- Отношения без искусственного «плюса за спасение», но долговременная психологическая модель только частично реализована.
- Предельная память контекста MCP сейчас 1000 последних сцен; при превышении нужно полное архивирование/checkpoint, иначе ответ честно помечается неполным.
- Браузерная сессия хранится в localStorage: перед боевым запуском нужен аудит CSP/XSS, CSRF/Rate limits и полный тест Supabase Auth.
