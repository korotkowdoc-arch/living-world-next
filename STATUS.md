## Реализовано, но ещё НЕ подтверждено настоящим использованием
- [ ] **ChatGPT OAuth end-to-end не завершён:** Supabase зарегистрировал отдельного public-клиента NEXT, несколько авторизаций одобрены, но обмен на действительный токен и вызов `list_worlds` из ChatGPT не подтверждены. `oauth_e2e_verified:false` остаётся корректным.
- [ ] Общий Supabase OAuth `Site URL` в предыдущей проверке указывал на старый `living-world-a3c.pages.dev`; тот сайт выдаёт устаревший consent, несмотря на GitHub CI другого Pages-проекта. На NEXT есть единый экран согласия с отдельной проверкой Bridge/NEXT. **Менять глобальный Site URL без проверки старых ссылок восстановления паролей нельзя**. До получения доступа пользователя к панели Auth не считать исправленным.
- [ ] Реальная запись сцены через MCP → отображение на iPhone и повтор квитанции при настоящем разрыве связи.
- [ ] Полное восстановление настоящего пользовательского архива в Safari и тесты двух независимых реальных OAuth-сессий/RLS; автоматические проверки и `ROLLBACK` SQL не заменяют этот опыт.

## В разработке и запланировано
- [ ] Восстановление архивов существенно больше 5000 сцен/30 МБ через безопасную пакетную загрузку: стадиирование, контроль целостности каждого пакета, атомарный финал, очистка незавершённых импортов.
- [ ] Автоматическое извлечение предложений о событиях из сыгранных неразмеченных сцен с дословными цитатами и подтверждением контекста. Сегодня есть буквальный поиск, **не** недостоверный «автопарсер фактов».
- [ ] Игровое время/расписания/обязательства независимых персонажей: учитывать доступность, маршруты и последствия, не создавать несыгранные события во время отсутствия пользователя.
- [ ] Предметы и экономика с транзакционной проверкой владения, неизвестных остатков, источников и конфликтов.
- [ ] Масштабные литературные испытания на реальных длинных историях, не подменять живое повествование шаблонами «все примирились» или «можно я...?».
- [ ] Более экономная память на десятки тысяч сцен: доказательные checkpoints и релевантный поиск по точному тексту без загрузки всей цепочки.

## Известные риски и ограничения
- OAuth Server и его Site URL общие для нового и старого миров, но приложение, клиент и данные раздельны. Изменение Supabase Auth может повлиять на старые email/password reset ссылки.
- SHA-256 защищает от случайного повреждения резервного файла, **не удостоверяет автора**. Восстановление делает новые ID и не перезаписывает существующие миры.
- Литературные подсказки и текстовые совпадения не подтверждают фактов. Только процитированная сцена и валидированное событие могут установить достоверное последствие.
- CI/syntax/SQL transaction `ROLLBACK` не доказывают, что интерфейс идеально работает на реальном iPhone.
