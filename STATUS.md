## Готово и проверено автоматическими тестами

- [x] Mobile-first веб-приложение для iPhone, быстрый старт мира из одной фразы без анкет.
- [x] Постоянные принципы инициативы NPC и отсутствия обязательного примирения, направленные отношения и независимые запреты на примирение/уважение.
- [x] Редактируемые естественно-языковые директивы с аудитом и версией; мир/исходные правила создаются одной SQL-транзакцией (миграция 003).
- [x] Истории — неизменяемые сцены, ветки, строгая проверка родителя, точная ревизия «На это» одной транзакцией, отдельные квитанции.
- [x] Источники фактов/знаний/отношений/денег/вещей и их проверка в JS; аннулированные сцены не смешиваются с действующей веткой.

- [x] Полнокорпусный поиск, получение точных сцен, история событий конкретного героя, полный экспорт всех веток с SHA-256.
- [x] iPhone PWA shell с отдельным от личных данных кэшем, вкладки «Поиск»/«Персонажи», режиссёрская диагностика литературных клише.
- [x] **v0.4:** долговременная структурная память `nw_active_memory_page` с проверкой неизменной вершины ветки; 50 000 сцен максимум за чтение, не скрывается неполнота.
- [x] **v0.4:** самостоятельные планы NPC `plan` с жизненным циклом, запретом на автоматическое завершение и источниками в сценах. MCP `get_npc_agency` и список на iPhone.
- [x] **v0.4:** безопасная повторная запись после сетевого сбоя: на iPhone одинаковый пакет получает стабильный `request_id`, сервер сверяет сам пакет, не только ID.

## Известные ограничения

- Локальные тесты/успешный GitHub CI — **не** доказательство работы SQL или настоящего OAuth. Отсутствующий облачный доступ нельзя подменить имитацией.
- Необходимо применить миграции 001–004 в точном порядке после базовой схемы. Без 004 новый `get_world_context` не загрузит память.
- `plan` фиксирует цель и подтверждённое изменение состояния; это не самостоятельный LLM, который выполняет действия во время молчания пользователя.
- Надёжность семантики персонажей выше благодаря строгим правилам, но никакой эвристический парсер не гарантирует хорошую литературу. Примерно сформулированные запреты могут не превратиться в структурный lock; исходный текст директивы всегда сохраняется.
- Коннектор ChatGPT использует подписку пользователя для текста; сайт не получает прямой доступ к этой подписке как к API.
- Структурная память ограничена 50 000 сценами за один запрос; без разметки текст сцен надо читать отдельно. Перечитывание очень больших цепочек ещё требует оптимизации/checkpoints.
- Резервная копия сейчас проверяется и выгружается, но **не импортируется обратно**.
